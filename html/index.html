HTML (HyperText Markup Language) is the most basic building block of the Web. It defines the meaning and structure of web content. Other technologies besides HTML are generally used to describe a web page's appearance/presentation (CSS) or functionality/behavior (JavaScript).

Learning Objectives

  • What HTML is and why it is used.
  • The difference between HTML, CSS, and JavaScript.
  • How websites and web browsers work.
  • Text editors and development tools (Visual Studio Code and Chrome).
  • Creating your first HTML file.
  • Saving files with the .html extension.
  • Opening an HTML file in a web browser.
